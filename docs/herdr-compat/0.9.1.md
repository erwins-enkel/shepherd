## Human triage (added after the run — preserve across reruns)

Zero REVIEW items, so nothing the checker raised needs a verdict. What follows are release-note
changes with **unchanged flags and schemas**, which S4's `--help` diff and S2's schema diff cannot
see by construction. Each was traced to its consumer by hand.

### Terminal observers are dropped after 30s without write progress (herdr #3612)

herdr now disconnects a terminal observer that stops accepting output, and says plainly that
"an interrupted stream may end without a final close record". `SocketPtyBridge` classifies exactly
that shape — process exits after the first frame, no `terminal.closed`, no deliberate `close()` —
as `onAbnormalExit`, which stamps a failure memo so the browser's reconnect avoids the socket path
(`src/socket-pty-bridge.ts`). On 0.9.1 a merely _slow_ client could therefore trip a path that so
far only fired on genuine mid-stream death or version skew.

**Decision: no change now.** The socket terminal is behind a default-OFF sub-flag and is documented
as not yet good enough to replace node-pty (Codex has no scroll lever, #1642). The live terminal
contract still passes (L9). This needs a second look **before** that flag is flipped, not before
the ceiling moves — recorded in the bump-history table so the next person meets it there.

### `pane split` without a target now splits the calling pane (herdr #4123)

No consumer: Shepherd never invokes `pane split`. `pane.split` appears only in the generated
protocol types, never in a call site (`grep '"pane.split"' src/ --exclude-dir=generated` is empty).

### `agent focus` / `pane move --focus` now move attached clients (herdr #3760, #4153, #4171)

No consumer. `agent.focus` and `pane.move` likewise exist only in the generated protocol;
`src/turn-end-backstop.ts` merely mentions `herdr agent focus` in a comment about a live
observation, and calls nothing.

### New global `--machine <label-or-id>` flag (herdr #3918)

Visible in the regenerated CLI reference (`docs-site/.../reference/cli/index.md`) — additive, and
Shepherd drives no machine-scoped command.

### Fixtures and floors

`gen:herdr-fixtures`, captured against an isolated 0.9.1 server with a populated workspace, yields
the **same four methods with identical `type` and `resultKeys`** as the committed manifest; the
only diff was the generator's unformatted JSON, removed by prettier. Floors unchanged:
`HERDR_LAST_FULL_SANDBOX_STATUS_VERSION` stays 0.7.4 on L7's evidence, external-registration 0.7.5
and first-pane-control 0.7.3 untouched. Protocol stayed 22, already allowlisted, so
`HERDR_SOCKET_SUPPORTED_PROTOCOLS` needed no edit.
